# 头部与机械臂方案演变

整理于 2026-10-20，当前路线更新于2026-11-05。这里只记录决策依据；旧路线的网页、扫描数据、试验脚本、接头 CAD 和有限元网格已清理。当前方案见 [项目入口](README.md) 与 [轴向供弹说明](pick_place_study/README.md)。

## 当前选择

六轴机械臂用专用夹爪抓住头部两侧承重耳，搬运到车侧安装座，底部定位、锁紧后松爪。头部保留交龙轮组、M3508、SM11、C620及居中相机/计算机；10～12格轴向弹盘、主动直推、俯仰及锁紧驱动留在车侧，仓与头共用俯仰托架。头部无电池、无图传模块。

选择的主要原因：机械臂只搬运，不持续承受射击瞄准载荷；弹丸独立格位，最低格直接对准入口，主动推送覆盖最后一发。当前仍是概念几何与质量预算，供弹台架、底部锁紧和实际夹取轨迹尚待设计验证。

## 走过的路径

| 阶段 | 探索内容 | 留下的认识与转向原因 |
|---|---|---|
| 交龙参考拆分 | 从 HERO.STEP 提取发射核心，在 FreeCAD 重绘一个摩擦轮环形件 | 原 STEP 只能恢复实体，不能恢复参数历史；简单环形件的参数修改和原几何对比通过。保留核心参考、来源记录和该试件。 |
| 上置供弹 | 浅仓＋六槽拨盘、立式转鼓、蛇形单列 | 先选浅仓拨盘，后来容量收敛到 3～5 发。相机和计算机统一移到测速上方；头部不装图传。减少体积并不能自动解决末弹、倾斜和出口交接。 |
| 臂上背部下插 | 双导向、拉钩、横楔、双剪插销；局部背板有限元 | 平桌不能提供固定挡墙，模块无电池，因此导向、承力和主动锁紧必须分工。背部接口偏离重心会放大弯矩；旧有限元只算局部背板，不能证明完整接头可靠。 |
| 承重旋钩 | 取消另行伸入的承重舌，用旋钩承重并预紧，独立机械防退 | 简化了动作链，但同步传动、预紧和公差仍未落地。当前底部接口只继承“头侧被动、车侧主动、触点不承力”的分工，旧钩廓、背板尺寸和电机预算不直接复用。 |
| 顶部直插／提篮 | 六轴拓扑、杆长、取头、取矿、存矿、空臂收纳扫描 | 顶部近重心抓取减小接口弯矩，但对腕部接近方向、退出空间和整臂构型提出约束。旧成功率受几何简化影响，不能据此认定取矿存矿和收纳已解决。 |
| 近重心斜接口／腕部瞄准 | 保留六轴，比较腕部提供俯仰、头部独立 pitch、七轴想法 | 放开头部基准点固定约束后，六轴腕部可在简化模型中覆盖 −15°～+45°；独立 pitch 又增加质量和支架空间。实际连杆错层及关节外壳仍是障碍，未形成可制造整臂方案。 |
| 夹爪搬运、车侧落座 | 五槽平盘＋侧耳／顶梁、六槽限装五发、立式五格、专用三槽 | 从臂上持续瞄准转为搬运安装。侧耳不增加头高；底部统一被动接口。五槽平盘最初是紧凑基线，但重力弯管的驱动交接不完整。 |
| 轴向五格直推（前期基线） | YZ 盘面、X 轴分度、格位直接对准入口，两级伸缩推头 | 取消 90°重力弯管。推头把球送到假定的摩擦轮接管位置；用伸缩机构压缩尾部长度。代价是伸缩传动、互锁、尺寸和重量余量都较紧。 |
| 车侧储弹（当前） | 完整形态考核连续10发，单盘10～12格、共俯仰托架、落座后伸套接通 | 保留单球直推，弹仓及驱动不由机械臂搬运。相机/LBC3 V2与真实器件进入根目录`frontend/`的总装工作台，执行器、底座和夹爪仍为占位。 |

## 值得保留的历史证据

- **背部弯矩的量级：**旧接口算例采用 2.716 kg 头部、前偏心 210 mm，重力静矩约 5.60 N·m；加速度和载荷系数后更大。这说明偏心必须与质量一起优化，不能把该值当作新底座的设计载荷或某个电机轴的扭矩。
- **旧臂结果的局限：**后期对相邻连杆增加局部检查后，旧的 61 条取矿成功路径在同平面直杆占位下均未保留，存矿保留 37/53 条。检查又裁去了关节附近区域，尚不构成真实外壳校核。因此旧最优杆长和关节电机表不作为当前任务的定型依据。
- **腕部瞄准的范围：**一组旧六轴布局在简化模型中完成了 625 个 pitch/yaw 姿态与 6,871 次边插值检查，最小已检查间隔约 6.96 mm。它说明轴系存在探索空间，不说明制造、取矿或动态射击已经通过，也不证明必须或不必使用七轴。
- **供弹转向的直接原因：**平盘候选在 +45°时，弯管出口比局部最低点高约 21.82 mm，原立式候选约 27.38 mm；没有连续主动驱动，停下的最后一发不能靠重力保证到达出口。抓取形式或少装两发不会消除这一缺口。
- **五发基线取舍：**轴向方案的概念包络约 393×158×201 mm，五发头部预算 2.7375 kg，含 240 g 夹爪约 2.9775 kg。相对旧五槽平盘约多 9.9% 包络和 265 g。这里的质量尚未称重；长度距 400 mm仅余约 7.3 mm，3 kg额定负载也仅余约 22.5 g。

## 规则版本与后续使用边界

早期路线依据 20260909 前瞻和部分 2026 合成取矿、存矿任务。当前依据改为 `references/` 中 20261015 发布的三本 2027 正式手册，原 PDF 均保留。联盟赛没有取矿、存矿任务；若研究超级对抗赛，需要用相应正式规则重新建任务。

机器人 600 mm收纳不计可拆模块；模块自身仍要满足 400 mm收纳、6 kg和无电池等要求。联盟赛工作台外廓 750×450 mm、高 400 mm且有切角，安装／拆除地点和首发识别判定均需考虑。前期五格网页的搬运路径是布局假设，没有解六轴 IK，也未验证实际收臂。
