# 轴向五格＋二级主动推送

2026-10-20 整理。当前只保留这一方案；[历史路线及转向依据](../DESIGN_HISTORY.md)集中记录。

入口：[三维演示](../magazine_study/pick-place.html#axial5)。参数：[config.json](config.json)，计算结果：[study.json](study.json)。六轴臂用两侧承重耳夹取头部；底部落座锁紧后松爪，射击承载和 pitch/yaw留在车侧。LBC3现有机箱与相机居中布置于测速上方，头部无图传、无电池。

## 几何与动作链

- 转轴沿炮口X方向，盘面YZ；球心圆R42 mm、外径138 mm、五个46 mm格位，深43 mm。盘中心(-120,0,42) mm，最低格球心(-120,0,0)直接对准发射入口。
- 前固定限位板只有发射工位开口，后板留推杆孔；每格需轻弹性保持，出口止弹片常闭，转盘断电定位。保持件形状、保持力、孔口公差尚待设计。
- 推头端面初始X=-154 mm，位于后板之后5 mm；终点X=-29.25 mm，将名义Ø42.5 mm球心推到X=-8 mm。总行程124.75 mm，前12.75 mm为接近球，随后球心主动移动112 mm。短直导路含前板通孔约59 mm。
- 按R30 mm、半轴距49 mm理想圆轮粗估，首次接触球心X≈-15.02 mm，接管目标深入约7.02 mm。未解软轮、U槽和弹丸变形。推头不越过轮轴平面，发射由原摩擦轮完成，入口轮座需重画。
- 两级伸缩各长88 mm、相对伸出62.375 mm、搭接25.625 mm，收拢最尾X=-245 mm。传动意向为电机／丝杆带动一级、内部同步带带动二级；锚点、槽口、导向截面、刚度、限力、寿命及实际器件未完成。
- 出口止弹片横移52 mm，名义让开余量6 mm；闭合片距转盘前端仅0.5 mm。孔口夹剪、跳动和变形需先验证。

动作：**推头退净 → 分度到位／锁止 → 轮组就绪后开止弹片 → 推出 → 确认出球 → 推头退净 → 闭片 → 下一格分度**。反馈确认仅为演示假设，不能把时间轴直接当作实际控制。缺出球反馈时的恢复动作须经台架验证。

页面支持暂停／拖动、只留末弹、−15°～+45°观测俯仰、XZ剖视和YZ盘面。演示不自动扣减初始质量预算。导出101帧推送状态及101帧腕部目标；均不是可执行控制程序或已解算的关节轨迹。

## 底部接口与搬运任务

头下被动底框保留三点承压面、定位键和两枚拉紧销，浮动触点不承力。车侧主动双钩预紧并机械防退，确认锁止和供电通信后才能松爪。这里只继承旧旋钩的功能分工，钩形、公差、传动和驱动负载须重新计算。

抓取侧耳位于[-12,±68,64] mm，名义腕部TCP[-12,0,166] mm。夹爪从上方接近、沿Y闭合，指尖台阶承重；掌部、指厚、防转接触与退出净空尚待实体设计。

演示假设：工作台高400 mm，头部原点从(-290,0,470)抬至675 mm，横移到X300 mm，再落到Z380 mm的车侧座。底盘占位360×360×250 mm。路径没有求六轴IK、碰撞和收臂；下一轮按真实抓手、安装座和完整取放轨迹优化杆长、轴线与泊位。导出法兰+Z向下、+X朝炮口、+Y与头部Y相反；实际CAD完成后重新标定。

## 复算与检查

仓库根目录执行，仅需Python标准库：

```bash
python3 mechanical/hero_head/pick_place_study/build_study.py
python3 mechanical/hero_head/pick_place_study/feed_geometry_check.py
python3 -m unittest discover -s mechanical/hero_head/pick_place_study/tests -v
```

[axial_feed.py](axial_feed.py)与网页[src/axial-feed-motion.js](../magazine_study/src/axial-feed-motion.js)保存同一动作函数。4项单元检查覆盖末弹接管位、两级搭接及退净、互锁、接触目标连续性。浏览器检查真实网格包络、Python/JS质量／重心、101帧一致、末弹+45°、落座锁紧后退爪、导出、窄屏及直接打开HTML。运行检查脚本会生成本地`browser-checks.json`，不纳入版本。这些检查不验证卡弹概率或供弹可靠性。

网页构建与启动见[网页说明](../magazine_study/README.md)。首个实物目标是单格直推台架，测−15°、0°、+45°末弹从静止入轮，再做五格分度互锁与连续循环。
