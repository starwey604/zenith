# 车载储弹，装头后接通弹路

2026-11-05。保留六轴臂夹取侧耳、底部落座、车侧承载与俯仰；将五格仓、分度和推送驱动从可拆头移到车侧。当前比较入口：[构型示意页](index.html)。参数计算：`python mechanical/hero_head/vehicle_feed/calculate.py`，结果见[results.json](results.json)。

接口电气与固定分工另见[触点和S145保护方案](ELECTRICAL_INTERFACE.md)，包括10项触点功能及6组短接/12组误接矩阵。

## 优先路线：车侧弹仓与头部共用俯仰托架

“车载”首先指**留在车上、不由机械臂搬运**，不要求弹仓一定固定在底盘不随俯仰运动。将仓、推送器、对接弹路和头部安装座放在同一车侧pitch托架，yaw也整体旋转。这样在−15°～+45°范围内，供弹接缝的相对位置不变；用受约束格位和主动直推处理倾斜，而不是让末弹靠重力走弯管。

可拆头保留：轮组/电机、测速模块、视觉组件、短直导路、被动接收口、底部定位锁销和侧耳。车侧保留：弹仓、分度器、推送驱动、弹路伸缩接头、主动锁紧、pitch/yaw及其驱动。

### A：单层10～12格轴向盘＋直推（优先）

盘面YZ，转轴X，最低格对准发射入口。继承五格方案的“格位→直导路→摩擦轮接管”，只改变容量和机构归属。首版按12发布局，10发作为收窄对照；12发是工程余量，不是已核实的规则最低容量。

- 格位孔46 mm、最小名义腹板3 mm，圆心半径 `R≥49/(2sin(π/N))`。沿用原盘径向余量27 mm，10格外径约212.6 mm，12格约243.3 mm。
- 盘的转动及重力载荷改由车侧轴承、托架和pitch驱动承担。不会因为机械臂变轻就消失，整车质量、pitch转动惯量、收臂和600 mm收纳都要重新检查。
- 逐格保弹、前后限位、常闭出口和机械定位沿用；推杆退净后才能分度。推杆仍需主动跟随末弹到入轮位置。
- 12格盘更高更宽；在旧核心与支脚基准下估算组合高度约286.3 mm，尚未包含新驱动、对接件和整车布局。该值不是总装CAD尺寸。

### B：前后双六格盘＋分仓顺序直推（短径向备选）

两盘同轴前后布置，先打空前盘六发，再将前盘锁在空工位，后盘逐颗经前盘空通道送入头部。每盘外径约152 mm，比单盘12格小，但后仓更长。

这是第二优先候选：必须把前盘空工位做成连续限位导路；后盘送球时前盘禁止转动，两个盘的止弹/保持件不能阻挡通球。后排推头行程需增加两盘间距，不能套用124.75 mm旧行程。两个有弹格位同时串通会形成双球/夹球风险，需分仓门与实际接触验证。它适合“高度卡死、前后空间尚可”的底盘，不是免费缩小单盘。

### C：底盘固定大仓＋主动提升＋跨pitch转接（后续容量路线）

底盘固定仓经有序主动输送，到yaw/pitch轴附近，再通过受控转接机构接入头部。储弹不会增加pitch惯量，容量也容易扩大，但多了活动接缝或软管。

第一版不优先：42 mm球让转接通道、轴承、弯曲半径和正向驱动占据明显空间。普通软管里靠后球顶前球，在姿态变化、长球列与末弹时不能保证连续；绕pitch轴的转接也会引入球跨缝时的夹剪。需要明确每一段由什么驱动、如何防倒流和清空，不能只画一条管线。若保留头侧一发终端推送器，要把它的质量重新加回头部。

## 赛前装填与赛后退弹

前端已补上单盘后上方装填口，见根目录`frontend/`的“装弹”工作区：最高格后侧开Ø47 mm孔，前侧保持封闭；人工沿轴向放入一球，球完全入格且手退出后，保持开盖点动下一格，全部装完再关盖。装填时禁止推送和发射，装填时俯仰回零。装填口与底部发射通道分开，不需拆头或拆整块挡板。逐格库存支持部分装填，退弹从同一口反向取出。

联盟赛规则V1.0.0（20261015）印刷页17–18允许三分钟准备阶段预装42 mm弹丸；初始允许发弹量为0。第36页补给区兑换的是发弹额度，不会补充实弹。第54页R7规定弹丸来源，第R8–R9条要求赛后清空归还。因此10/12格仍是打样与考核容量；整局容量另需战术预算，不能靠网页“重新装满”补足。

翻盖、锁扣、开盖检测和取球工具需实物细化；网页展示服务通道及操作互锁，不含手指/工具碰撞。具体坐标和操作入口见`frontend/README.md`。

## 弹路连接不能靠下插时硬碰硬

A/B优先采用两阶段接入：

1. **竖直落座、机械锁紧。** 车侧输送口缩回，双方止弹关闭；没有水平凸管挡住头部从上方下降。
2. **车侧短行程伸套对接。** 锁紧确认后，车侧接头沿炮口轴线接近头侧接收口。约8～12 mm只作为首个布局参数，靠导向面、径向小浮动与硬限位定位，不靠软管找准轴线。
3. **接通检测后打开出口。** 接头内部形成连续支承面，球道不能有凸台、露缝、螺钉头；定位、承力和锁紧由底座负责，弹路套不承受头部重量。
4. **单球推送、退净、关门、下一格。** 推送器在车侧，头上没有带电弹仓；摩擦轮就绪后才送球。
5. **拆头前先清空接缝。** 确认推头已退、短导路无跨缝球、两端止弹关闭，再退套、解锁、抓走。若球卡在接缝，保持机械锁紧并排故，不能强行剪球拆头。

伸套、保持件和闸门本身仍需实体设计。先做单球断开/接入试件，测错位容纳、推力峰值、球擦伤和卡滞；然后做十发以上连续送弹。

## 质量与负载口径

- 10发名义质量445 g，12发534 g。旧五发夹爪负载2.9775 kg仅加五发就到3.2000 kg，还没增加仓结构。
- 旧共用头部预算2.015 kg＋侧耳55 g＋新增被动接收口/短导路暂取120 g＝**空头2.19 kg，含夹爪2.43 kg**。接收口预算80～180 g时，头部约2.15～2.25 kg。发射核心1.2 kg等原假设尚未由新STEP赋材或称重确认。
- 12格盘仅弹丸的pitch重力矩，在示例轴心X=-30、Z=0 mm、仓面X=-120 mm、俯仰−15°～+45°和逐发库存下最大约0.684 N·m；10格约0.524 N·m。**这不是pitch电机选型扭矩**，还缺头、盘、驱动、托架自重、惯量、加速与射击载荷。
- 车侧弹仓不计入机械臂抓取负载，但应计入整机质量、伸展和收纳；能否按车侧而非可拆模块计重/检录，需要按实际模块划分核对。可拆头必须保留实质发射功能，不能只留下测速外壳。

### 一个会改变安装高度的反例

不能直接照搬旧演示的头部原点高380 mm和底盘顶面250 mm。若俯仰轴X=-30、Z=0，后推送器保留X=-245、下缘Z=-14 mm，在+45°时该后角世界高度只有约218.1 mm。若其水平位置仍落在底盘上方，就会与底盘相交；仅给该角10 mm离面间隙，轴高就需约421.9 mm。该单点算例未代替全总装碰撞，但已经说明：A路线需要抬轴、缩短/重排车侧推送器，或给后仓留扫掠空腔，不能只换弹仓归属就沿用旧安装高度。
