# 车载供弹头：对接触点、故障保护与安装分工

2026-11-06更新。裁判四芯建议采用**车侧保护/控制板＋头侧接收/保护板**，用成熟保护器件或经验证的小模块组成专用接口载板。不是直接把裁判系统原四根线延长到弹针，也不是仅加一颗保险丝。尚未选定连接器型号、限流值或PCB尺寸，本文件供电气和机械共同定接口。

## 规则实际上有两种不同测试

依据仓库内《RoboMaster 2027机甲大师高校系列赛机器人制作规范手册V1.0.0（20261015）》印刷p.76，S145：

| 被测端 | 施加的故障 | 合格目标 |
|---|---|---|
| 重装机器人引出的裁判四芯航空线端子 | 不接外部电源，任意两线短接；车上裁判系统按正常运行状态检查 | **车侧裁判系统仍正常工作**，不是只求没有烧毁 |
| 可拆42 mm模块引出的裁判四芯端子 | 不超过30 V外部电源的正负端任意接到两针上 | 头侧裁判系统可以离线，但**不能损坏**；包括正反极性误接 |

图3-36的线序为1 GND（棕）、2 CAN_L（橙）、3 12 V（红）、4 CAN_H（黄）。这是标准裁判接头的编号；新盲插总连接器的腔位编号另定，不把两者混用。

S114（p.57）另要求Ammo-Booster断电时，摩擦轮、拨弹盘等发射机构也断电。**车载盘和推杆移到车上后仍是发射机构，不能改接Mini PC电源绕过断电控制。** 按S113与表3-4，电脑使用Mini PC接口独立供电，但不得通过CAN、GPIO或保护二极管反向给已断电执行器供电。

## 推荐预留12项电气功能，不等于12根同规格弹针

| 逻辑号 | 功能 | 电源/信号归属 | 结构要求 |
|---|---|---|---|
| F1/F2 | FIRE+、FIRE_RETURN | 受Ammo-Booster控制的头侧摩擦轮电源，暂按24 V级 | 独立大电流触点；额定/峰值、压降和温升确定后选型，不按小弹针默认承载 |
| A1/A2 | MINIPC_24V、MINIPC_RETURN | 电源管理模块Mini PC接口24 V，经触点直接进LBC3顶板 | 顶板承担电脑保护与降压，不另设外置模块；与FIRE正电源分开，电机大电流不经电脑回线 |
| R1…R4 | REF_GND、REF_CAN_L、REF_12V、REF_CAN_H | 独立受保护的裁判接口，对应标准四芯功能 | 独立小信号分区，REF地不随意并到动力/电脑地或安装板 |
| C1/C2 | CTRL_CAN_H、CTRL_CAN_L | 自有控制链路：电脑、车侧控制、电调等；默认相对Mini PC回路定义 | 与REF_CAN是两条总线；是否增加隔离和参考地由收发器共模与供电域确定 |
| D1/D2 | PRESENT_LOOP两端 | 头侧被动短接片/识别电阻，车侧受保护低能量检测 | 不依赖电脑开机；用于确认接触完成，不能代替底座锁紧传感器 |

可交付给机械/电气的[触点功能表](contact_functions.csv)与[18项裁判端口故障矩阵](referee_fault_matrix.csv)已附，故障项均标为未测试。

这是12项功能，物理上可能采用两组功率插接件＋一个8位信号触点盒，或同一混合连接器。若控制CAN最终需要独立信号参考地，则增加第13项；高电流触点并联也可能增加物理触点数。并联电流不能按额定值简单相加，应核对接触不均、温升与失效一针后的工况。

不跨接：MIPI（相机和电脑均在头内）、头部图传（不装）、拨盘/推送电机各相线（驱动均在车侧）。CAN终端按实际总线拓扑设置，不在每块板或每个接头上都固定加120 Ω。

## 保护电路要分车侧和头侧

```text
车内裁判主链路
   │
   ├─ 电源隔离/独立限流支路 ───┐
   └─ CAN故障段隔离/切离 ─────┤
                              ├─ 受保护外露REF四芯触点
                              │           │
                              │      头侧输入保护
                              │       ├─反接/过压关断/防倒灌→稳定12 V→SM11
                              │       └─CAN耐直流误接/必要的隔离→SM11 CAN

Ammo-Booster → 发射支路保护/开关 → FIRE触点 → 动力分电＋CAN分线板 → 两块C620 → 两个M3508
            └→ 车侧盘、推送、止弹等发射执行器
自有CAN → C1/C2触点 → 同一块分线板 → 三路CAN：LBC3 / 左C620 / 右C620
Mini PC接口24 V → A1/A2触点 → LBC3顶板24 V输入 → LBC3/相机
```

本轮接线图采用用户确认的LBC3顶板24 V输入，保护与降压由顶板承担；Ammo-Booster电源与自有CAN在头内接入同一块普通分电＋CAN分线板，输出两路电调电源与三路同总线CAN；LBC3仅从该板接CAN，收发器已集成在LBC3顶板上，不再单画外置模块；电源仍独立来自Mini PC。不加外置削波或泄放模块。电调瞬态行为与顶板输入耐受需按实际硬件确认。裁判保护框是功能要求，具体电源隔离的位置与CAN两侧供电域须在原理图上展开。**保护覆盖到外露端子**，不是只保护板子内部；REF供电回流、机壳、USB调试器和屏蔽层也不能偷偷把隔离域接回动力地。

### 车侧：短路不能拖垮主控和其他裁判节点

- 12 V支路有独立限流、热保护及必要的隔离供电/防倒灌，外口短路不能拉低整个裁判供电。中继的主链路侧供电不能取自同一会被短掉的支路。
- **电气隔离不等于故障隔离。** 普通物理层CAN中继逐位转发，外口持续显性或错误状态可能影响主链路。必须选有故障段切离能力且满足测试的成熟中继，不能只看“隔离2500 V”。[HMS关于repeater与bridge的区别](https://support.hms-networks.com/hc/en-us/articles/26594758726674-CAN-repeater-or-CANbridge-Which-device-is-more-suitable-for-my-CAN-network)。
- 若改用双CAN控制器的帧级桥接，应保持帧类型、ID、DLC和数据不变，故障端错误状态不传播到另一控制器；同时验证延迟、ACK行为、总线负载、无回环和SM11上线/校准。这是备选实现，不是把两颗收发器的TX/RX直接交叉连接。
- 中继/桥接是否符合官方裁判链路接入要求，以及正常运行标准，需结合官方接口资料和实际检录确认；不改官方模块本体和固件。

### 头侧：外部30 V可以出现在任意一对线上

- 12 V输入需要反接隔离、过压关断、限流/防倒灌；误接30 V时不必开机，应优先关断而非硬把多余电压烧在小板上。
- CAN_H/L对外误接要考虑正负直流电压、未上电状态与电流回路，不能只看ESD瞬态能力。必要的高耐压总线保护/过压断开位于终端及低压器件之前；若有小电流钳位，必须算持续故障功耗。
- 一颗120 Ω终端被直接跨接30 V时功耗为 **30²/120=7.5 W**。收发器宣称±70 V耐故障，不能顺带证明终端、TVS和其他连接器后电路能承受同一故障。
- 同时检查REF_12V对CAN、REF_GND对CAN、CAN_H对CAN_L等回路；12组有向误接会包含不同供电和浮地情形，不可只测红黑线反接。
- REF地与Mini PC/FIRE地的连接必须有明确电气域设计。测量SM11外壳、安装螺钉/支架及屏蔽是否导通；必要时在安装处绝缘，但保留官方要求的固定和外露区域。

## 买模块还是画板：先验证模块，再做紧凑载板

**推荐最终做自有接口板，先用成熟功能块搭台架验证。** 头侧放轻量接收/保护和触点，车侧放功率开关、中继及互锁。普通淘宝“隔离CAN模块”“防反接模块”不能独立覆盖S145；没有完整故障资料的模块只能当候选。

可以从器件资料确认已有的功能：

- [TI ISO1042](https://www.ti.com/product/ISO1042)：CAN总线直流故障保护±70 V、数字隔离；它是MCU逻辑到CAN的收发器，**不是CAN口到CAN口的完整中继**，也不含SM11的12 V供电保护。
- [TI TPS2663系列](https://www.ti.com/product/TPS2663)：60 V级eFuse，带可调限流/过压与软启动等；反接与反向电流功能需按对应外置FET电路实现。可用于合适电流范围的保护支路候选，不直接据此确定整头功率通路。
- 不能因SM11是小信号设备就随便用低电流模块。[SM11 2020官方参数](https://www.robomaster.com/zh-CN/products/components/detail/2597)给最大功率17 W，按12 V估计约1.42 A；还要给隔离转换损耗和启动留量。800 mA级器件不默认够用。实际源端供电能力仍需核对。
- [Harwin弹性触点目录](https://www.harwin.com/ezi-range/spring-contacts)可供选连接件；不同触点电流等级差异很大，应按完整料号核定工作压缩量、触点电阻、额定电流、寿命和镀层。

向供应商索取：原理图或保护框图、全部输入组合的直流耐受、上电/断电时的行为、短接时另一CAN段是否正常、限流/热恢复、CAN速率和终端配置、体积质量。先拿数据再买，不指定未经验证的成品“隔离板”作为检录保证。

## 接触件在机械上怎样放

推荐在**头下被动底框侧边做独立可更换触点盒**，避开后方轴向弹路、转盘扫掠区、推杆和拉紧销。电接口与弹路接头各自浮动，固定在同一个车侧pitch托架上，不能让弹路伸套带着触点一起拉扯。

- 头侧用有护边的平齐接触片；车侧用弹针/弹片与单独功率触点的浮动盒。头放桌上时四脚先着地，触点不碰桌面，护边防碎屑和散落金属短接。
- 导向与承力件先接合，触点后进入工作压缩量；靠三点承压、定位键与独立机械锁承载，不能让弹针顶住2 kg头部。
- 浮动盒使用限位肩螺钉/导向等确定的结构，允许有限XY找正，Z向靠硬止挡控制压缩；不要靠PCB弯曲或松螺钉获得浮动。浮动行程、公差、接触力和闭锁预紧统一预算。
- 动力与信号分区，中间留绝缘隔墙；不在相邻小间距弹针中交错排24 V与REF/CAN。防180°反插，图纸同时给出公母对接视图，避免镜像接错。
- 参考回路可设计先接后断，PRESENT最后接通/最先断开；这由有保证的接触行程和公差实现。**动力上电仍靠车侧开关**，不依赖插接顺序来承担热插拔保护。
- 触点盒是耗材模块，螺钉可拆、背面有应力释放和检修空间；含保险/保护板的维护入口应在可接近侧，不藏在转盘与弹路正下方。
- 保留清晰可访问的标准四芯航空测试接口。测试接口和实际盲插REF触点经过相同保护路径，不用与实机不同的“检录专用旁路”；接口形式与使用方式检录前确认。

## 电气与弹路动作互锁

```text
落座/导向 → 机械锁到位 → PRESENT稳定
→ 接通Mini PC电源及受保护REF支路，确认电压与通信
→ 车侧弹路伸套接通 → 确认安全条件
→ 在Ammo-Booster允许下开启FIRE → 轮组达到目标转速
→ 允许分度与推送
```

锁紧传感器和弹路接通传感器在车侧，不另占头侧触点。拆卸时先禁止新球、清空接缝、等待轮组安全停转，关FIRE及需断开的电源、确认放电后退弹路套再解锁。PRESENT抖动/通信掉线应撤销发射许可并禁止下一次推送，不用反复大电流重启去试接触。异常断电时机械锁保持，不自动掉头。

电脑上电和弹路连接的具体先后可以在安全边界内调整；上面的核心条件是**未锁紧不得上动力、未接通不得推球、裁判断发射电源时所有相关执行器不得继续工作**。

## 出板前的验收矩阵

1. 车侧四线组合为6种短接：GND/L、GND/12 V、GND/H、L/12 V、L/H、12 V/H。车载电源和裁判系统按正常运行检查，无外部电源灌入；除被隔离故障支路外，主控/其他裁判节点持续正常。
2. 头侧4针任选正负得到12组有向误接，逐组检查至30 V；故障持续时间、外源限流等按实际官方检录方法确认，不能靠把测试电源限流调得很小来声称通过。
3. 同时覆盖头上其他电源断开/接入等实际可出现状态，防止Mini PC、FIRE、CTRL_CAN、USB或机壳形成隐藏回流；移除故障后确认SM11可恢复，且无持续漏电、异常温升和损伤。
4. 正常功能：SM11校准/上线、两轮起转、电脑运行、车载盘/推杆工作时的数据、压降与温升；Ammo-Booster断电时逐项检查发射执行器确实失能，非仅软件停转。
5. 机械：盲插错位、未完全压合、触点弹跳、污染与多次插拔；动力不得在半接触状态接通；锁紧与弹路不能被触点盒顶偏。

先用假负载、替代CAN节点及可更换保护板验证故障，再连接昂贵的官方模块进行正式等效测试。S145并未给出一个通用限流/保持时间，本文件不另行把任意台架条件定义成检录标准。

下一步可冻结：12项功能分组、头下侧置可换触点盒、车侧独立受保护电源、REF/CAN与自有控制分开。功率触点料号和数量等实测摩擦轮起转电流/电脑负载后确定；裁判保护板先完成故障台架再收敛PCB。


## 底座与线束页面（2026-11-06）

整头接线打开 `/wiring.html`，可按支路高亮、单独展开并下载SVG和触点CSV；电脑、电调、MIPI与裁判保护分别绘制。数据共用`frontend/src/dock/model.ts`，A1/A2的编号与位置不变，名称改为MINIPC_24V/MINIPC_RETURN；程序内AUX分区键为兼容既有几何和导出继续保留。

在根目录前端打开 `/dock.html`，分别查看导向锁紧、12项触点映射和两侧焊线预留。功能定义沿用上表；新增C0只作为可能需要的控制参考地空间，没有指定接法。车侧接触面与头侧底视图互为左右镜像，逻辑编号不变；页面可导出功能CSV和当前布局参数。

机械意向采用外圈粗导向、圆销＋菱形销精定位、三点承压和双侧拉紧。销距90 mm、销Ø8/孔Ø8.2、触点名义压缩2 mm和PRESENT短0.8 mm均是布局参数；精度、压缩范围和先后时序须由最终料号与公差链确定。触点盒XY浮动暂留±0.8 mm，固定/止挡与服务弯需联合设计。

主盒占位108×42 mm，另有C0备用位14×24 mm；安装耳和防反插凸台未包含在主盒尺寸。以4 mm绝缘外径、8 mm硬焊尾、12 mm热缩直段、中心线R=16 mm、净空3 mm作空间预算，每侧盒背后留41 mm、90°弯曲侧向留21 mm；按当前焊尾基准，头车闭合总高预算116 mm。这里不指定铜截面、额定电流或厂家最小弯曲半径，保护板与整束服务弯需另外留空。

页面的线束为路径示意，REF_CAN与CTRL_CAN在实物中各自双绞。车侧导线不得拉住浮动盒；先以服务弯隔离浮动，再在固定托架处做应力释放。完整保护电路和S145故障台架仍按本文前述要求实施。
