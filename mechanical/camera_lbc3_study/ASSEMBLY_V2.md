# 第二版：排线与维护空间

[三维预览](viewer_v2.html) · [FreeCAD装配](cad/camera_lbc3_v2.FCStd) · [整套STEP](cad/camera_lbc3_v2.step) · [单件下载](exports/v2/index.html) · [几何检查结果](verification_v2.json)

本版落实了机箱出口夹、相机端夹和排线自由段，原V1文件与访问入口保留。当前可做空间试装；实际线材额定弯曲半径、厚度、端部插入和相机接头姿态尚需实物确认。

## 为什么相机位置变了

相机图中FPC座靠PCB下边。原光轴高22 mm时PCB下边只有6 mm高度，下面再放排线回弯与应力释放件很紧。本版光轴局部高度改为30 mm、PCB背面X=22 mm，留下底部回弯空间。

相机相对机箱中心沿Y移2.763 mm，使排线自由段不必横向扭弯。光轴仍是整头的安装基准：后续将整个组件在头部支架上相应居中，电脑机箱相对光轴小量偏置，不是将相机挂到侧边。

加入夹具、护框外移安装耳后，本版包络为 **139.3×106.5×54 mm**，不含全部紧固件、外部插头与整头安装架；V1为137.3×106.5×46 mm，不混用两版底架和相机/护框孔位。

## 排线自由段

按12 mm宽、0.3 mm厚的平排线作几何占位，整段在固定Y平面内弯曲，没有绕长轴强扭。路线从假定的转接板接头外自由点，先水平到机箱出口，再下弯、底部回转，从相机底边向上接入。

- 两处圆弧中心线半径取5 mm；这是空间假设，不是供应商保证的最小半径。
- 自由段长约46.1 mm；**不含两端插入连接器的长度**。实际下单长度应再加两端插入量与安装余量，不直接买46 mm排线。
- 底部中心线最低Z=3 mm，厚度0.3 mm时最低表面约2.85 mm；底架上表面Z=0。
- 机箱接头实际接触平面、相机座高度和线厚未完全明确，当前线端均为几何对接意向，不代表已插入真实夹锁。

排线按实际接触面方向选正/反款，本轮不展开针序审查。上电前核对两端3.3 V与GND等定义。

## 新增的夹持件

1. **机箱出口夹座 `NEW_ExitSaddle`**：固定到底架，承受线缆拉力，不靠CAM1的B2B接头承受拉力。
2. **出口压条 `NEW_ExitJaw`**：两颗M1.6螺钉意向，固定座Ø1.4盲导孔；螺纹配合按打印材料试配。上下各留0.25 mm软垫压缩后间隙。
3. **相机端压条 `NEW_CameraCableJaw`**：装在相机座新增的底部固定横梁上，两颗M1.6横向固定；前后各留0.35 mm软垫压缩后间隙。

出口软垫沿线宽约13 mm、沿线长4 mm；相机端约13×4 mm。应按实际厚度与材料选垫，不让硬塑料边直接挤伤排线，也不压在裸露触点或连接器翻盖上。软垫刚度、预压和抗拉能力没有做实物测试。

护框的M3固定孔移到侧壁外侧安装耳。原先位于侧壁正下方的孔虽然可以建出来，却无法从上方进螺丝刀；本版修正了这一装配问题。

## 推荐试装顺序

1. 固定机箱底座及主板，插合实际CAM1转接板，确认对插完全后再安装支承/压条和软垫，不能用压条强压歪斜的接头。
2. 将带安装耳底座装到共底架，固定相机座；护框暂不装。
3. 以四个M1.6孔固定相机PCB，检查四角接触区与元件、螺母、垫圈的净距。
4. 打开两端FPC翻盖，插入排线并锁好；留自然回弯，不折出死角。
5. 装机箱出口夹与相机端压条，逐步调整软垫，让线缆固定但不被挤伤。先完成夹持再测试插拔/拉扯影响。
6. 上盖沿Z向上开合检查；相机端压条与相机安装螺钉从前方维护时先拆护框。
7. 最后装护框，确认镜头调焦、完整图像边缘和热风路。再将整个组件装入头部，核对底面螺母工具空间与测速周边约束。

## 当前检查能说明什么

`build_v2.py`运行中检查了8个新结构件的单实体及有效性、当前零件体积穿透、排线自由段与装配件的穿透、实际转接板与现有参考的穿透，结果均无冲突。

另检查了上盖向上抬1～50 mm（每1 mm一档）的刚体扫掠，以及指定螺钉位置的工具轴：M3按Ø4 mm细工具轴，M1.6按Ø3 mm细工具轴。相机正面维护时移除护框。结果无当前几何冲突；未覆盖完整手柄、手指、紧固件头、动态翻盖和实物线材，因此不能将结果当成全部可装配性已实测。

相机后接头仍依据图纸留包络；CAM1板Z=0.85 mm的对插基准仍需实物确认。本轮不把这些未知量隐含改成已知尺寸。

## 重建与查看

FreeCAD/FreeCADCmd运行 `build_v2.py`，输出V2 CAD、STEP、试装STL、网格与检查JSON。脚本以本版固定尺寸重建；FCStd里的参数是只读记录，并非可单独编辑驱动全装配。调整排线半径/相机位置时要同步调整夹具及底架孔位并重跑检查，不能只修改参数记录。

仓库根目录构建预览并检查：

```bash
NODE_PATH="$PWD/mechanical/hero_head/magazine_study/node_modules" mechanical/hero_head/magazine_study/node_modules/.bin/esbuild mechanical/camera_lbc3_study/viewer_v2.js --bundle --minify --outfile=mechanical/camera_lbc3_study/viewer_v2.bundle.js
node mechanical/camera_lbc3_study/checks.mjs --v2
```

普通无参数的`checks.mjs`仍检查V1入口。V2三维页增加排线显示与走线侧视；分解模式用于看零件，不表示连着排线实际拆装的轨迹。
