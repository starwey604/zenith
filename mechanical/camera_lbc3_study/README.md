## 本版交付与使用

实际装配包络 **137.3×106.5×46 mm**，不含未完整建模的螺钉头、螺母、外部插头及排线。相比最初130.3×106.5×44 mm规划，机箱安装耳、底架和独立护框增加了前后及高度空间。

新增五个零件：3 mm共底架、带安装耳/板边支承的机箱底座、带双侧肋的四角相机座、可拆护框、转接板压条。机箱上盖沿用原件；原`lbc3_case_v1`未改动。

- 实际CAM1模型已从`~/下载/CamAdaptor.step`收集到[mechanical/steps/CamAdaptor.step](../steps/CamAdaptor.step)。其FPC有22个0.5 mm节距触点，板体厚约1.564 mm，含器件整体约23.975×18.275×4.624 mm；不再用旧30P占位代替。电气线序不能由STEP确认。
- 以B2B本体中心对齐旧CAM1基准，板下表面暂取原板框Z=0.85 mm。实际对插深度未测，需试装再定。旧宽托台与该板背器件约4.35 mm³穿透，已改为两侧空白板边支承；转接板压条配约0.986 mm软垫间隙，软垫材料与预压需试配。
- 新零件均为单实体、有效BRep；新件彼此、与当前机箱/电路参考及转接板没有检测到体积穿透，两个假定相机插头空间也未被新件占用。这里没有完整LBC3原厂板上元件，也未检查所有紧固件、工具与真实FPC活动范围。
- 相机四孔按Ø2建参考，支座用Ø1.8穿孔供M1.6紧固意向；底架/安装耳用Ø3.4通孔配M3及螺母。转接板压条留Ø1.7盲导孔供M2短螺钉塑料试配，不是已成形螺纹。试装确认长度、垫片和塑料孔配合后再展开采购。
- STL为试装稿，提供底座、相机座、护框、压条；共底架建议3 mm金属板，提供STEP。切片时仍需核对支撑、材料和孔补偿；未实测受力、散热或打印装配。

### 重建

在FreeCAD/FreeCADCmd中执行`build.py`，例如FreeCAD Python控制台：

```python
p='/home/ww/codings/zenith/mechanical/camera_lbc3_study/build.py'
exec(compile(open(p).read(),p,'exec'), {'__file__':p})
```

这是**脚本尺寸驱动重建**：修改`build.py`中的尺寸再运行；FCStd里显示的参数是只读版本记录，直接编辑它们不会驱动形体。模型没有声称恢复原件特征历史或全部草图约束。脚本读取已有机箱和实际转接板，生成独立文件；运行前另存本目录模型内的手工修改。

## 从相机图确认了什么

图纸第1页，型号 **DECXIN-3478V1**：

| 项目 | 图中标注／设计使用方式 |
|---|---|
| PCB | 32×32 mm，厚1.6 mm |
| 四角安装 | 28×28 mm孔距，Ø2孔；以板中心计孔心(±14,±14) mm |
| 镜头外圆 | Ø17 mm |
| 轴向 | 镜头最前端到板背面标22.1±0.2 mm；另一尺寸20.3±0.2 mm。图中差值1.8 mm与板厚1.6 mm有0.2 mm差别，不能据此反推零件细分厚度；包络先用22.3 mm上界 |
| 排线座 | 22P、0.5 mm间距、翻盖、下接触；在背视图下边 |
| 额外插针 | 3PIN、1.25 mm，STRB/TRG/GND；要留背面外伸与插拔空间 |
| 接口供电 | 22P第1脚标3.3 V；下表AVDD/DOVDD/DVDD数值不能当作整板供电口电压 |
| 视场 | H112°、V82.6°、D123°；用于护框和周边遮挡初筛 |

PCB背面器件高度、排线座完整外形/开盖轨迹、额外插针外伸、安装孔公差、孔周允许压紧区、镜头实际可转动部分与质量未明确。22.3 mm轴向预算不包含未标注的背面插头与排线弯折。

## 为什么不直接做一个大一体壳

| 做法 | 取舍 | 结论 |
|---|---|---|
| 现有机箱＋共用金属底架＋独立相机座 | 相机固定基准不随开盖变动；两件分别维修；复用现有散热和接口窗口 | **首选** |
| 新一体打印壳，前面直接装相机 | 外形有机会更整洁，但要重做机箱、散热、全部接口开口；盖板和热变形影响光轴，维修要拆整套 | 等布局与线束稳定后再决定是否整合外罩 |
| 相机挂在机箱上盖或侧边长悬臂 | 安装简单，但上盖刚度、反复拆装与悬臂振动都进入光轴定位链 | 不采用 |

“共底架”不等于两个设备必须共用一块大实心底板。可以是两根短纵梁、横梁、前相机立架和侧肋组成的轻量骨架；打印件承担外罩与线夹，主要光轴定位优先交给金属支架。最终材料、板厚与紧固方式按惯性、振动和加工能力确定。

## 推荐布局：电脑水平转90°，相机在其前方

原机箱98.5×81×34 mm保持不变。原板框的+y为CAM1排线出口，将机箱绕竖轴旋转−90°，使该出口面朝相机：

- 新局部X朝镜头前方，Y向左，Z向上。
- 机箱占X=-81…0，Y=±49.25，Z=0…34 mm。
- 相机PCB背面暂放X=20 mm，光轴Y=0、Z=22 mm；PCB占Z=6…38 mm，四孔高度Z=8/36 mm。
- 镜头最前端名义X=42.1 mm，按最大深度为42.3 mm。相机后方有20 mm排线/插座预留区。
- 连同底架、护边的初步规划包络约 **130.3×106.5×44 mm**；不含外部供电/网口插头、线束转弯、整头安装座和全部螺钉头。

旋转只发生在水平面，不把电脑立起来或侧挂。电脑顶面风扇依旧朝上，机箱两侧的网口/USB与USB-C/HDMI转为左右分区。旋转后要给实际使用的插头和检修工具留侧向空间；底架横梁不挡现有前侧排风缝。

这里的20 mm是设计假设，不是排线最小弯曲半径。先用实物接头及排线验证，必要时增加间距；不要用折死FPC的方式强行满足130 mm长度。

## 相机座怎么固定

1. 以PCB四角孔为基准做短支承柱或后托框，支承面落在经确认没有元件的角部。图纸Ø2孔不直接当作M2自由通孔；首版可考虑M1.6穿装螺钉与小垫圈，或等厂家确认后采用对应紧固件。
2. 四角均支承，避免只用中间两孔或让镜头长期作为悬臂晃动。垫圈、螺钉与支柱不能压到元件、焊点和排线座；孔周可压紧区还需实物确认。
3. 相机座下方用短立架与两侧肋连接共同底架；不用一个细长L片远伸到相机背后。镜头固定壳体若需要辅助托持，应避开玻璃和调焦环，不通过强压镜头来拉平PCB。
4. 与头部固定使用明确定位面/定位特征加螺钉。第一版先设光轴与炮口平行，俯仰微调优先用可换垫片或调节后锁死的结构；不要把一条长槽加单螺钉摩擦当作最终定位。
5. 相机护框与安装基准分开；拆护罩、开电脑盖时不拆相机定位螺钉。支架周边保留螺丝刀、镜头调焦和FPC翻盖操作空间。

现有LBC3机箱原螺柱也只是空间验证稿。底架夹持机箱底座或新增独立安装耳，不默认把上盖四个自攻孔当成整机安装点；开盖应保持底座固定。

## 不做深镜头筒：这个镜头很广角

镜头H112°，半视场56°。如果护边伸出镜头前端3 mm，以整个Ø17 mm镜头端面保守投影，开口至少约：

- 水平：`17 + 2×3×tan(56°) ≈25.9 mm`
- 竖直：`17 + 2×3×tan(41.3°) ≈22.3 mm`

首版护框可先留约30×28 mm开口，前伸不超过这个3 mm假设；或只做上下/侧向保护耳。不要做紧贴Ø17的长圆筒。实际入瞳位置未提供，最后须用完整画面检查暗角和周边遮挡；上述计算不替代光学校核。

相机与测速模块的全局高度尚不在这一步冻结。下视场会看到前方测速/炮口，桥架高度要按真实姿态复核；还需遵守测速模块Logo附近的磁性/易磁化材料约束，包含风扇和螺钉。整个支架和机箱随头运动，不用车侧弹巢充当相机支撑。

## 排线需要改配，不能只换个壳

早期CAM1参考小板按30P FPC座占位。现在已收到实际22P转接板STEP，机械上直接用它替换旧占位，无需再叠一块30转22中间板；是否与相机引脚完全匹配，仍需对应原理图核对。

机械上预留原转接板后伸、22P座、翻盖和排线服务弯；电气上要核对CAM1到相机22P的电源、GND、I²C与四路MIPI映射。22P针数相同也不能保证排线接触面、线序正确。图纸的STRB/TRG若本阶段不用，可不插线，但插针实体仍要避让。

排线两端分别做应力释放，夹持在柔性绝缘垫或专用压条上，不把拉力传给小板B2B连接器。默认不用跨转动关节的排线，也不在机箱缝里夹死FPC。长度与弯曲半径按实际线材确定后再定线夹位置。

## 散热与振动

- 机箱原风扇进风与排气槽都保留，新增护罩不形成封闭热腔；相机前支架不能包住电脑的进排风面。
- 不在相机与电脑之间单独使用柔软悬挂，以免相机相对发射核心改变姿态。若实测需要隔振，应比较整个视觉组件或发射核心的振动路径，再决定隔振位置。
- 相机和电脑共底架主要解决定位与走线，不代表已经解决摩擦轮振动；首版检查起轮前后图像抖动、固定件松动、长时间温升与焦点变化。

## 第一轮样件与待补尺寸

已完成共底架、四角相机托座、可拆护框和带安装耳底座；转接板压条也已放入装配。相机参考固定32×32、孔距28及Ø2孔，名义轴深22.1 mm并留0.2 mm前端余量。实际FPC未收到，线夹尚未冻结。

优先补的不是整套新STEP，而是：**相机背面侧照/卡尺尺寸、22P座和3PIN插针最高点、孔周允许压紧区、实际排线及质量**。同时确认相机随附镜头是否就是图中版本，后续不能用图中22.1 mm去限制另配镜头。

完成几何布局后，先检查插头插拔、盖板拆装、线夹应力释放和四角固定，再装到头上验证光轴、视场与摩擦轮振动。当前交付为首版结构装配及试装零件，尚缺真实FPC、相机背面详细几何与紧固件试配，不能直接当作已完成实机验证的生产图。
