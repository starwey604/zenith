# LubanCat-3 机械件 / 40pin 顶板

这个目录放 LubanCat-3（RK3576 一体板，85×56mm）上叠加的机械结构：
一块盖在板子上的**顶板**（同时是 40pin 扩展板 PCB），用 **4 根 M2.5 柱**
固定在板子自带的 4 颗螺丝孔上，既压住摄像头的 B2B→FPC30 转接小板，又给
RK3576 上方挂一颗风扇。

- 模型源（参数化）：[`model.py`](model.py)
- FreeCAD 文档：`lbc3_hat.FCStd`
- 坐标系：**板框坐标**，原点 = LBC3 PCB 左下角（俯视），z=0 = PCB 上表面，
  单位 mm。

在 FreeCAD 里重新生成：

```python
exec(open('/home/ww/codings/zenith/mechanical/lbc3_hat/model.py').read())
build()
```

## 结构栈（从下往上）

```
  case / 底部
  └─ LBC3 PCB (1.6)                       z=-1.6 .. 0
       └─ [gap = 40pin 对插高度]          z=0 .. GAP
            ├─ 40pin 公母排针（电气+定位）
            ├─ SoC (RK3576) + 风扇         贴在板上方
            └─ 4× M2.5 柱（铜/尼龙，长度=GAP）
  └─ 顶板 PCB (1.6)                        z=GAP .. GAP+1.6
       ├─ 4× M2.5 过孔，对准板子固定孔
       ├─ 风扇开孔 + 4 颗风扇螺孔
       └─ 摄像头 B2B 转接板压持位（待定）
```

## 待确认参数（`model.py` 里标了 `# TBC`）

| 参数 | 现在取值 | 需要确定 |
|---|---|---|
| `BOARD_T` | 1.6 | 实物板厚 |
| `GAP` | 11.0 | 40pin 对插高度，同时要容下风扇；决定 M2.5 柱长度 |
| `FAN_*` | 40mm/10mm/32mm | 风扇规格、螺孔距，以及风扇在板上的中心（SoC 位置） |
| `B2B_*` | 20×8×3 @ (38,51) | 转接小板的位置/尺寸/高度（顶板下压点） |
| 顶板覆盖范围 | 整板 85×56 | 是否要避开边缘连接器，或加大开孔/缺口 |
| 固定孔 | 上述 4 点 | 实物复核 + 顶板过孔取 Ø2.7~3.0 |

## 与官方 STEP 的装配检视

官方 `3D模型/Lubancat3_3D_Model.STEP`（577 零件）已导入。STEP 坐标系：
**板平面 X–Z、法线 Y**，PCB 上表面 y=0、下表面 y=−1.6；映射 `step=(板x, 板高, −板y)`。

实测（来自 STEP）：

| 项目 | 值（板框坐标） |
|---|---|
| RK3576 SoC 中心 | (58.5, 32.2) |
| 40pin 公针尖高度 | +8.54（即 GAP=8.5 对插） |
| 网口 HR911130A 占位 | x −3.0 … 18.4（左边缘） |

- 顶板按 GAP=8.5 放置后，与板上**所有零件做布尔求交：0 碰撞**。
- 高度校核：8.5(GAP) − 4(风扇) = 4.5mm 给散热片/间隙，与"铝鳍片 ~3mm"吻合。

### 仍需确认（见下）

- 摄像头 B2B 转接板的**准确连接器位置**（当前占位在板 (57,52)）。
- 电源入口（24V→5V）的**实际外形/位置**（当前开孔占位 x68–84 / y8–20）。

## DXF 导出（给 EDA / 结构用）

`dxf/`（由 `export_dxf.py` 生成，坐标系 = 板框，原点在板子左下角，单位 mm）：

| 文件 | 内容 |
|---|---|
| `dxf/lbc3_top_plate.dxf` | 顶板外形（左切到 x=18.4、顶边缺口、R1.5）+ 4×Ø2.7 固定孔 + Ø16 风扇孔 + 4×Ø1.8 风扇孔 + 2×Ø2.2 压条孔 + 电源开口；并标注 **40P 母座位**（本体框 + pin1 圆 + 文字） |
| `dxf/lbc3_board.dxf` | LubanCat-3 底板外形（R1.5 + 缺口）+ 4×Ø2.6 固定孔；并标注 **CAM1 B2B 位**（本体框 + 文字） |
