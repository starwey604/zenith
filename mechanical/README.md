# LubanCat-3 机械件 / 40pin 顶板

这个目录放 LubanCat-3（RK3576 一体板，85×56mm）上叠加的机械结构：
一块盖在板子上的**顶板**（同时是 40pin 扩展板 PCB），用 **4 根 M2.5 柱**
固定在板子自带的 4 颗螺丝孔上，压住 CAM1 的 B2B→FPC30 转接小板，并给
RK3576 上方挂一颗风扇。转接小板的 FPC 端从鲁班猫 3 后沿伸出。

两件式 3D 打印外壳的第一版在 [`lbc3_case_v1/`](lbc3_case_v1/README.md)。
它给顶板上的 XT30 和两只卧贴 2Pin GH1.25 预留了窗口；连接器焊盘布局
尚未确认，不能直接作为生产面板开孔。

- 模型源（参数化）：[`model.py`](model.py)
- FreeCAD 文档：`lbc3_hat.FCStd`
- 坐标系：**板框坐标**，原点 = LBC3 PCB 左下角（俯视），z=0 = PCB 上表面，
  单位 mm。

从仓库根目录运行 FreeCAD 宏重新生成并保存带颜色的装配文档：

```bash
FreeCAD mechanical/lbc3_hat/rebuild.FCMacro
```

也可以在 FreeCAD Python 控制台里只生成一个新文档：

```python
exec(open('/home/ww/codings/zenith/mechanical/lbc3_hat/model.py').read())
build()
```

## 结构栈（从下往上）

```
  case / 底部
  └─ LBC3 PCB (1.6)                       z=-1.6 .. 0
       └─ [gap = 40pin 对插高度]          z=0 .. GAP
            ├─ 40pin 公母排针（电气+定位）
            ├─ SoC (RK3576) + 风扇         贴在板上方
            ├─ CAM1 转接小板 (1.6)          z=0.8 .. 2.4
            │    ├─ 底面 AXE630124D → LBC3 CAM1/J16 AXE530127D
            │    └─ 顶面 KH-FG0.5-H2.0-30PIN（位于板后沿之外）
            └─ 4× M2.5 柱（铜/尼龙，长度=GAP）
  └─ 顶板 PCB (1.6)                        z=GAP .. GAP+1.6
       ├─ 4× M2.5 过孔，对准板子固定孔
       ├─ 风扇开孔 + 4 颗风扇螺孔
       └─ 摄像头 B2B 转接板压持位
```

## 待确认参数（`model.py` 里标了 `# TBC`）

| 参数 | 现在取值 | 需要确定 |
|---|---|---|
| `BOARD_T` | 1.6 | 实物板厚 |
| `GAP` | 8.5 | 40pin 对插高度，同时要容下风扇；决定 M2.5 柱长度 |
| `FAN_*` | 18mm/4mm/15mm | 风扇实际型号、外形与孔距 |
| CAM1 转接板固定 | 压条 + 泡棉，当前名义接触 | 泡棉实际压缩量、支撑方式与插拔受力 |
| 顶板覆盖范围 | x18.4–85 / y0–56 | 是否还要避开其余边缘连接器 |
| 固定孔 | 上述 4 点 | 实物复核 + 顶板过孔取 Ø2.7~3.0 |

## 与官方 STEP 的装配检视

官方 `3D模型/Lubancat3_3D_Model.STEP`（577 零件）已导入。STEP 坐标系：
**板平面 X–Z、法线 Y**，PCB 上表面 y=0、下表面 y=−1.6；映射 `step=(板x, 板高, −板y)`。

实测（来自 STEP）：

| 项目 | 值（板框坐标） |
|---|---|
| RK3576 SoC 中心 | (58.5, 32.2) |
| 40pin 公针尖高度 | +8.54（即 GAP=8.5 对插） |
| 网口 HR911130A 占位 | x −3.0 … 18.4（左边缘） |

- 顶板按 GAP=8.5 放置后，与板上**所有零件做布尔求交：0 碰撞**。
- 高度校核：8.5(GAP) − 4(风扇) = 4.5mm 给散热片/间隙，与"铝鳍片 ~3mm"吻合。

### 仍需确认（见下）

- CAM1 转接板伸出后沿部分的外壳空间、机械支撑与排线弯折空间。
- 电源入口（24V→5V）的**实际外形/位置**（当前开孔占位 x68–84 / y8–20）。

## CAM1 转接小板（底层板）

V2R0 官方原理图 `SCH/LubanCat3_EBF410513V2R0_SCH_20260521.pdf` 第 27 页
明确写明 CAM1 是 J16，型号 `AXE530127D`。配对 header 是 `AXE630124D`。
`KH-FG0.5-H2.0-30PIN` 的本体约 19.4×6.0×2.0mm，原 10×10mm 占位不够。

新板形为一片式窄颈加后沿宽端，仍采用板框坐标（从上往下看）：

| 部位 | 范围 / 中心（mm） | 用途 |
|---|---|---|
| 窄颈 | x34.45–44.45, y47.0–55.3 | 经过板载红外器件与 FPC 座之间 |
| 斜肩 | y55.3–56.3 | 左右各 1mm 过渡 |
| 宽端 | x27.45–51.45, y56.3–65.3 | 后沿外的 24×9mm FPC 安装区 |
| 底面 B2B 本体 | 中心 (39.45,51.28)，7.8×2.0 | 与 CAM1/J16 对插；名义对插高度 0.8 |
| 顶面 FPC 本体 | 中心 (39.45,60.3)，19.4×6.0 | 排线朝 +y 方向插入 |

板厚 1.6mm；转接板下表面 z=0.8、上表面 z=2.4，FPC 座顶面 z=4.4。
按 V2R0 官方 STEP，对新板形和 FPC 本体进行实体碰撞检查，除 B2B 正常对插区域外，
与鲁班猫 3 元件无碰撞。宽端超出原板后沿 **9.3mm**，不含排线插拔与弯折空间。
它没有独立安装孔，量产前必须确定外壳/支架如何承受排线插拔力，并确认压条泡棉的
实际预压量。

FreeCAD 中两个连接器只表示本体机械包络；DXF 中的矩形也不是生产焊盘。
PCB 设计需使用器件原厂焊盘图，尤其注意**底面 AXE630124D 相对顶视图的针脚镜像**、
FPC 下接触方向和 CAM1 到排线的引脚映射。

## DXF 导出（给 EDA / 结构用）

`dxf/`（由 `export_dxf.py` 生成，坐标系 = 板框，原点在板子左下角，单位 mm）：

| 文件 | 内容 |
|---|---|
| `dxf/lbc3_top_plate.dxf` | 顶板外形（左切到 x=18.4、顶边缺口、R1.5）+ 4×Ø2.7 固定孔 + Ø16 风扇孔 + 4×Ø1.8 风扇孔 + 2×Ø2.2 压条孔 + 电源开口；40P 标注 = 本体框 + **40 个焊盘中心(Ø1.7)** + pin1 框（**在右端**，板子丝印如此）+ 文字 |
| `dxf/lbc3_board.dxf` | LubanCat-3 底板外形（R1.5 + 缺口）+ 4×Ø2.6 固定孔；并标注 **CAM1 B2B 位**（本体框 + 文字） |
| `dxf/lbc3_cam1_adapter.dxf` | CAM1 转接小板外形 + 底面 B2B / 顶面 FPC 本体包络，供结构与 PCB 布局参考（非生产焊盘） |

重新生成：`exec(open('.../export_dxf.py').read()); export_top_plate(); export_board(); export_adapter()`
