# LubanCat-3 机械件 / 40pin 顶板

这个目录放 LubanCat-3（RK3576 一体板，85×56mm）上叠加的机械结构：
一块盖在板子上的**顶板**（同时是 40pin 扩展板 PCB），用 **4 根 M2.5 柱**
固定在板子自带的 4 颗螺丝孔上，既压住摄像头的 B2B→FPC30 转接小板，又给
RK3576 上方挂一颗风扇。

- 模型源（参数化）：[`model.py`](model.py)
- FreeCAD 文档：`lbc3_hat.FCStd`
- 坐标系：**板框坐标**，原点 = LBC3 PCB 左下角（俯视），z=0 = PCB 上表面，
  单位 mm。

## 结构栈（从下往上）

```
  case / 底部
  └─ LBC3 PCB (1.6)                       z=-1.6 .. 0
       └─ [gap = 40pin 对插高度]          z=0 .. GAP
            ├─ 40pin 公母排针（电气+定位）
            ├─ SoC (RK3576) + 风扇         贴在板上方
            └─ 4× M2.5 柱（铜/尼龙，长度=GAP）
  └─ 顶板 PCB (1.6)                        z=GAP .. GAP+1.6
       ├─ 4× M2.5 过孔，对准板子固定孔
       ├─ 风扇开孔 + 4 颗风扇螺孔
       └─ 摄像头 B2B 转接板压持位（待定）
```

## 待确认参数（`model.py` 里标了 `# TBC`）

| 参数 | 现在取值 | 需要确定 |
|---|---|---|
| `BOARD_T` | 1.6 | 实物板厚 |
| `GAP` | 11.0 | 40pin 对插高度，同时要容下风扇；决定 M2.5 柱长度 |
| `FAN_*` | 40mm/10mm/32mm | 风扇规格、螺孔距，以及风扇在板上的中心（SoC 位置） |
| `B2B_*` | 20×8×3 @ (38,51) | 转接小板的位置/尺寸/高度（顶板下压点） |
| 顶板覆盖范围 | 整板 85×56 | 是否要避开边缘连接器，或加大开孔/缺口 |
| 固定孔 | 上述 4 点 | 实物复核 + 顶板过孔取 Ø2.7~3.0 |
