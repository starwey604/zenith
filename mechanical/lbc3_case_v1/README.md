# LubanCat-3 外壳第一版

这是两件式、可打印的**空间验证稿**，不是已验证装配的生产外壳。以鲁班猫 3
官方 V2R0 STEP、当前 40pin 顶板和 CAM1 转接板为基准；单位 mm，坐标系同
`../lbc3_hat/README.md`。参数化源文件是 [`case_v1.py`](case_v1.py)，
FreeCAD 装配是 [`lbc3_case_v1.FCStd`](lbc3_case_v1.FCStd)。

外包络 x=−7…91.5、y=−7…74、z=−12.5…21.5，即 98.5×81×34 mm。
底座和上盖在 z=6 分件，壁厚 2.4 mm、底厚 3 mm、顶厚 2.5 mm。
四角的外壳螺柱位于两块 PCB 外侧；底座有鲁班猫 3 的四孔支承柱和
CAM1 转接板后伸部分的托台。上盖给 18×18×4 mm 风扇留了进风孔，
前侧有三条排风缝。风扇固定仍依赖顶板原有的四个安装孔。

## 接口与预留口

| 位置 | 开口范围（板框坐标） | 用途 |
|---|---|---|
| 左侧 x=−7 | y=0.5…55.7，z=−4.5…18 | 网口及两组 USB |
| 右侧 x=91.5 | y=6…17、19…33、35…46，z=−2…8 | 两个 USB-C 和 mini HDMI |
| 后侧 y=74 | x=25…54，z=1…9.5 | CAM1 转接板的 30Pin FPC 排线 |
| 后侧 y=74 | x=57…84，z=8.5…17 | 顶板上的 PCB 焊接 XT30 |
| 右后侧 x=91.5 | y=44.5…65，z=9…17 | 顶板上的两个卧贴 2Pin GH1.25，暂作共用窗口 |

XT30 与两只 GH **都假定焊在现有 40pin 顶板上**（顶板上表面 z=10.1），
并非焊在 CAM1 转接板或独立接口板上。开口的位置和尺寸目前是留量，
不能作为连接器焊盘或最终面板孔图。XT30 尚未指定公母头及具体焊脚形式；
可参考 [Amass XT30 板式系列图册](https://www.china-amass.com/public/upload/20250401/e0fa64442511ae671ae3a6b076ec86ee.pdf)。
GH1.25 的侧进线器件可参考
[JST GH 系列图纸](https://www.jst-mfg.com/product/pdf/eng/eGH.pdf)。

**需要改顶板布局才能定稿：**当前顶板后沿止于 y=56，而右后角已有
(81.5, 52.5) 固定孔；在该孔和 USB-C2 之间的边缘空间不足以直接确认
两只 GH 的焊盘、插头、线束和孔位互不干涉。建议把第二只 GH 放到顶板
后右角的小延伸区（初步可考察 y≈58…65），第一只靠 USB-C2 后方；
XT30 朝后，避开 CAM1 排线区域。此延伸区**尚未写入顶板 DXF**，须拿到
确切 XT30/GH 型号和厂商焊盘图后再定尺寸。若不改顶板，可以改为两个
GH 分散在其它边缘，但外壳窗口也要跟着重画。

## 重建与使用

已导出两件按打印平台摆放的网格：
[`case_base_print.stl`](case_base_print.stl) 和
[`case_lid_print.stl`](case_lid_print.stl)。上盖在 STL 中倒置，顶面贴平台。
从仓库根目录纯命令行重建，不会弹出 FreeCAD 窗口：

```bash
printf 'exec(open("mechanical/lbc3_case_v1/rebuild.py").read(), {"__name__": "__main__", "__file__": "mechanical/lbc3_case_v1/rebuild.py"})\n' | FreeCADCmd -c
```

两件已通过 FreeCAD 的 `isValid()`、单实体及互不穿透检查。官方 STEP
的端口及板上零件范围已用于确定壳体高度和侧边接口开口；装配文档内
只保留端口简化包络，未嵌入 56 MB 的原始 STEP。**打印前仍需用实物试装**，
尤其是 40pin 对插高度、风扇高度、XT30 插头进深、GH 线束转弯半径、
FPC 弯折半径、外壳螺丝固定方式及各开口打印公差。
