# 固定种子长度补充采样结果

本轮以 Sobol 准蒙特卡洛方式在第 2–3、第 3–4 关节锚点跨度各 0.75–1.25 倍之间取 16 个二维候选点，并加入原长 1.0／1.0。xArm6、UR5e 两个参考构型与两个合法泊位共 68 项，全部完成且没有异常。每个候选继续跑和[五档网格](../length_sweep_grid_v1/README.md)完全相同的 67 项一至三级存矿、72 项取矿出口和 8 项基础路径；原始场景、存矿任务及计算代码哈希与网格结果一致，见 [manifest.json](manifest.json)。原始逐候选轨迹见 `candidates/*.json`，共约 177 MiB；摘要见 [summary.csv](summary.csv)。

[采样坐标图](plots/sobol_length_samples.png)按真实的两段跨度比率绘制每个点，颜色分别表示三级存矿、存矿分级均值和取矿出口完成比例；红色空心星标记原长。没有对未测试长度进行插值。[存矿／取矿权衡图](plots/storage_pickup_pareto.png)展示任务之间的取舍，黑圈只标出模块路径完成且在两个比例上互不支配的候选。

xArm6 约 **288.0／410.8 mm、`rear_center`** 的连续长度点达到一级 15/15、二级 25/25、三级 22/27、取矿 65/72、模块完成；这和网格约 276.7／416.2 mm 的领先点取得相同采样成绩。补充搜索没有找到同时超过网格领先点存矿和取矿成绩的候选，但说明附近不只有单个离散档位可达到这个成绩。UR5e 在约 **446.7／357.6 mm、`rear_center`** 的点使取矿达到 57/72，高于它在五档网格里的最高 56/72；相应三级为 12/27，模块路径未完成。

准蒙特卡洛抽样是有限设计候选的探索，不是实际任务发生概率的统计估计，也不能证明连续尺寸空间的全局最优。两段总长度、连杆质量、执行器力矩及结构强度均未约束；场地、核心、抓手和模块尺寸仍是合成设计假设。物理设计前还需补齐实测核心 P／Q 轴、碰撞包络、底盘路线、动态载荷和真实制造范围。
