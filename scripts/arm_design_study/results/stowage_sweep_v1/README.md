# Minimum stowage sweep v1

本目录是 2026-09-16 固定输入的首轮最小收纳包络结果。153 个独立构型/臂长组合全部完成、无 worker 错误，共执行 519,115 次姿态几何评估；3 进程累计 worker 时间 562.8 秒。

规则判据来自《RoboMaster 2026 机甲大师高校系列赛机器人制作规范手册 V2.0.0》PDF 第 35 页 S96：工程机器人必须存在一种 X/Y/Z 三向均不大于 `600 mm` 的状态。结果使用底盘、机械臂胶囊和末端工具的联合 AABB，并要求姿态满足关节限位且无胶囊自碰/底盘碰撞。

## 对 xArm6 担忧的解释

担忧有工程依据，但本轮不能把差值全部归因于曲臂。固定底盘/臂座条件下，xArm6 最小联合高度为 `822.0 mm`，Willow 为 `698.2 mm`，相差 `123.8 mm`；两者的 Z 上边界分别由 `link_0` 和 `link_1` 决定，说明基座到前两轴的固定堆叠高度是当前主因。xArm6 自身的最佳折叠包络反而是 `259.3×389.8×377.0 mm`，并未在三向都劣于 Willow 的 `311.4×203.7×517.4 mm`。

因此当前证据支持“直接照搬 xArm6 产品几何和 500 mm 安装高度不适合 600 mm 收纳限制”，尚不足以证明“所有带偏置/拐弯连杆的拓扑必然更差”。要隔离曲臂代价，需要精确的复合 link 外轮廓，并把安装高度加入搜索。

任务能力也不能忽略：最易收纳的 xArm6 q08 在原任务最佳泊位的三任务稳健通过率约 `79.4%`；xArm6 q01 仍有相同 `822 mm` 限制，但任务稳健通过率约 `90.3%`。最易收纳的 Willow q09 约 `3.9%`，此前任务最优 Willow q32 约 `13.0%`。当前应先修正安装高度/底盘模型，再用收纳约束重新做联合 Pareto 选择。
