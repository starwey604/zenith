# 250 mm 底盘最小收纳扫描

本轮使用确认后的 `360×360×250 mm` 底盘，并假设机械臂基座直接安装在底盘顶面，即臂坐标系原点位于本体坐标 `Z=250 mm`。旧的 `400 mm` 底盘与 `Z=500 mm` 臂座结果保留在相邻的 `stowage_sweep_v1` 目录中。

扫描复用了上一轮相同的 153 组构型/臂长样本，但没有继承旧底盘条件下的任务成绩。任务将在 chassis250 场景中另行重跑。本轮 153/153 完成、0 错误，共执行 560,942 次姿态几何评估，3 个进程累计 worker 时间 590.6 秒。

## 规则结果

- 136/153 组通过 `600×600×600 mm` 收纳判据。
- Lite6、PiPER、Unitree Z1、UR5e、WidowX250、Willow 0907 和 xArm6 的全部已测臂长均存在规则内收纳姿态。
- UR10e 的 17 组均未通过；其中最优 q08 为 `608.0×573.7×621.1 mm`，X 超出 8.0 mm、Z 超出 21.1 mm。
- xArm6 全部样本均由固定 `link_0` 把 Z 限制在 `572.0 mm`，只剩 28.0 mm 高度余量。它可以通过当前胶囊模型，但对精确外壳、裁判系统和线缆的余量偏小。

## 模型边界

结果仍是胶囊体设计筛选值。联合包络包含底盘、机械臂胶囊和末端工具，不包含裁判系统及支架、线缆拖链、紧固件和精确外壳 CAD。因此，xArm6 的 28 mm 余量不能直接视为检录安全余量；下一阶段应在任务重跑之后，把裁判系统占位和实体 link 外形纳入最终收纳复核。
