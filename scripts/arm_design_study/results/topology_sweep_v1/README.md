# 受约束六轴构型试运行：完整合成任务结果

## 结论

本轮 60 个候选全部完成且无运行错误。五种统一尺度的合成 6R 模板各包含基线和两个固定种子 Sobol 长度扰动，并在四个底盘泊位运行相同的 67 个一至三级存矿、72 个取矿越边沿、8 个基础任务及 9 个装配压力任务。

当前唯一的三任务 Pareto 候选是 `rm3p_spherical_wrist_q02_rear_right`：

- 轴心跨度 J2→J3 / J3→J4 / J4→J5 / J5→J6：`320.85 / 385.59 / 0 / 0 mm`；
- 一／二／三级存矿：`12/15`、`23/25`、`9/27`；
- 存矿均衡完成率：`68.44%`；
- 取矿越边沿：`59/72`；
- 基础模块装配：通过；
- 九位姿装配压力任务：`9/9`；
- 三任务稳健通过率：`68.44%`。

这说明在当前合成场景和统一尺度下，`J2∥J3∥J4` 的三平行折叠主臂值得继续研究。它不是最终结构推荐：第三个远端俯仰关节可能增加腕部质量、J2/J3 重力矩和结构复杂度，本轮没有载荷、刚度或电机实体模型。

## 证据边界

- 五种模板是统一尺度的轴线假设，不是完整 CAD；关节限位也采用共同设计假设。
- 碰撞体是直线胶囊，没有电机、叉架、线缆、轴承座和模块真实外形。
- 连续多起点 IK 失败不等于数学不可达；正式构型穷举需要枚举各任务点的逆解并用图搜索连续路径。
- 所有任务位置、障碍和卡口尺寸仍是合成假设。
- 本轮没有计算模块重力、压入力、卡口扭矩、连杆挠度、关节寿命或底盘倾覆。
