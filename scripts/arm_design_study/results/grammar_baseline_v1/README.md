# 受约束六轴构型全任务基线扫描

本轮是合成几何筛选，不是机械强度或实机可行性证明。生成器给出的 134 种六轴构型各在 4 个底盘泊位执行同一套任务，共 536 个候选，全部完成且无运行错误。机械臂安装高度为 250 mm。每个候选都运行一至三级存矿 67 例、取矿并越过边沿 72 例、基础任务 8 例及英雄头装配扰动 9 例；不含四级矿。长度取各构型的名义值，尚未做长度优化。

三任务 Pareto 前沿仅有以下两项，都是 J2、J3、J4 轴平行的 `zyyyzx` 布置。`存矿均衡率` 是一至三级各自通过率的平均值；综合最低率是它、取矿通过率与装配扰动通过率三者中的最小值，且要求基础装配通过。

| 构型 / 泊位 | J2→J3 / J3→J4 / J4→J5 / J5→J6 | 存矿 1/2/3 级 | 存矿均衡率 | 取矿 | 装配扰动 | 综合最低率 |
| --- | --- | --- | ---: | ---: | ---: | ---: |
| `orth6r_4ab675a33402` / rear_right；J5→J6 向上直线偏置 | 290 / 390 / 0 / 60 mm | 12/15、21/25、6/27 | 62.1% | 56/72 | 9/9 | 62.1% |
| `orth6r_d94907e07b06` / rear_right；J5、J6 交于同一腕心 | 290 / 390 / 0 / 0 mm | 12/15、18/25、6/27 | 58.1% | 59/72 | 9/9 | 58.1% |

上偏置方案在存矿均衡率上高约 4 个百分点，直连杆球腕方案多通过 3 个取矿案例。两者的轴线顺序和主要臂长相同，是下一轮比较腕部 60 mm 偏置、收纳尺寸及加工代价的直接对照。全体候选中，186/536 通过基础装配，118/536 通过全部 9 个装配扰动位姿。

`summary.csv` 可按构型、泊位和任务分数排序；`best_by_robot.csv` 给出每个构型的最佳泊位；`pareto_3tasks.csv` 记录非支配候选。`plots/configuration_overview.png` 展示存矿、取矿前列和各构型的装配通过数分布，`plots/three_task_tradeoff.png` 展示三任务权衡。`candidates.tar.gz` 通过 Git LFS 保存经校验的 536 份逐轨迹 JSON 报告，解包后位于 `candidates/`。`scene.json`、`spec.json` 和 `manifest.json` 固定本轮输入与哈希。

本轮用旧的逐点贪心 IK 作全量筛查；完整多逆解图搜索尚未用于全部 536 个候选，因此 `ik_failed` 不能解释为数学上不可达。碰撞使用胶囊体与盒体近似，尚未评分收纳、载荷、材料、关节力矩、线束及动力学。规则值与合成设计假设的来源以输入文件中的 `source_type` 为准。

名义长度的 [134 构型最小收纳搜索](../grammar_baseline_stowage_v1/README.md)现已单独完成；收纳不是上表任务分数的一部分。
