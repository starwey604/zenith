# 两构型、两段臂长、两泊位完整任务网格结果

这是一轮固定合成场景的六轴运动学几何筛选。100 个候选全部跑完且无异常，每个候选都有 67 项一至三级存矿、72 项取矿出口及 8 项基础路径记录。原始候选轨迹报告保存在 `candidates/*.json`，逐候选成绩见 [summary.csv](summary.csv)和 [summary.json](summary.json)，输入及代码哈希见 [manifest.json](manifest.json)。运行时未压缩原始 JSON，共约 262 MiB；发布前逐个校验了输入哈希和任务数量。

[长度热图](plots/length_heatmaps.png)每一行对应一个构型与泊位，横轴是第 2–3 关节锚点跨度相对原长的倍数，纵轴是第 3–4 跨度的倍数；三列依次为三级存矿、三个级别等权平均、取矿出口的采样几何完成比例。[存矿／取矿权衡图](plots/storage_pickup_pareto.png)中的黑圈标出模块路径完成且在这两个比例上互不支配的候选。颜色表示两段锚点跨度之和，而非整臂认证长度。

当前最有潜力的是 xArm6 参考轴线方案、第 2–3 段约 277 mm、第 3–4 段约 416 mm、`rear_center` 泊位。它的两段锚点跨度合计约 692.9 mm，而原长基准合计约 692.7 mm；成绩改善主要来自在两段之间重新分配长度，并非增加两段总长度。存矿分级均值从原长的约 87.8% 升至约 93.8%，取矿从 64／72 升至 65／72。若优先追求取矿角度覆盖，另一个 xArm6 点有 68／72，但三级从 22／27 降至 14／27。这两个点构成模块可行候选的二维权衡前沿。

领先点的三级五项失败中，四项首次出现在 P 轴转动且报告 `ik_failed`，一项在 Q 轴转动报告 `joint_jump`。已通过存矿路径的最小粗碰撞距离代理约 4.7 mm，三级最小关节限位余量约 0.080 rad；这些代理值不能作为实物装配间隙或安全系数，提示后续需要更细的几何和执行器验证。

本轮没有候选使六矿位各 12 个放置角全部通过；领先点的六矿位通过数为 11、12、12、12、10、8，仍需重点改进第 6 矿位。UR5e 网格里的 50 项模块路径均未完成，不能用单一合成模块任务直接断言这种工业轴线方案不适合实物。领先尺寸位于本轮 0.8–1.2 搜索范围的边界，因此还需要独立补充采样。所有场景、碰撞体、工具、P／Q 轴及底盘泊位均属设计假设；这份结果不计载荷、力矩、动态接触、底盘行驶或连续碰撞，也不能证明实物最优臂长。
