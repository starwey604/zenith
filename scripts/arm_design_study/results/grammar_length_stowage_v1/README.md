# 入围构型各长度的零间隙收纳搜索

对 7 种入围构型的 17 个长度样本逐一搜索最小几何收纳姿态，去重 4 个场地泊位后共 119 项。全部完成且无运行错误；118 项找到不超过 600 mm 的无穿透胶囊体姿态，唯一未通过的是 `orth6r_148133fca859_q01`。这里允许间隙为零，属于几何下限，不是制造余量。

任务最佳的两项长度样本均通过：`orth6r_ebb9ebb875ae_q07` 为 469.9 × 481.9 × 490.4 mm，但间隙近零；`orth6r_d94907e07b06_q07` 为 494.5 × 455.2 × 494.5 mm，间隙约 2.33 mm。因此还进行了独立的 [5 mm 设计间隙复算](../grammar_length_stowage_5mm_v1/README.md)。

`summary.csv` 给出每个构型与长度的尺寸、是否过限和任务最佳泊位，`candidates.tar.gz` 通过 Git LFS 保存所有收纳姿态与包络来源。`config.json`、`manifest.json` 固定输入、600 mm 规则参考和搜索参数。有限搜索未通过不等于无法收纳；实际外壳和线束尚未建模。
