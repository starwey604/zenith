# 重装结构工作台

打开总装，点选右侧结构或模型，查看部件来源和接口说明。切到“装弹”查看后上方装填口、逐格装弹和退弹；切到“供弹”可送一发或连续演示；切到“对接”逐步查看落座、锁紧和伸套接通；“视觉组件”独立查看相机＋LBC3 V2。

## 双用途夹爪方案页

从页头进入“双用途夹爪”，或直接打开 `/gripper.html`。A 为同步平行双指，B 为齿轮对开；同一副指尖使用软垫夹矿、刚性槽口捕获头部承力肩。切换“夹头 → 落座”“资源岛取矿”“存矿 → 退爪”，点击阶段或拖动进度观察；“近看接口”放大当前抓取处。地址保留候选、任务和进度。

页面中的头部、能量单元、支座和驱动均为参数化示意，不复用总装页的 CAD 作为新抓取接口已适配的证据。A 使用左右旋丝杆与直线导向意向；B 采用齿轮同步绕轴开合，槽口在夹头闭合位对齐，夹矿位的接触角尚待特化。能量单元长 150 mm、大端 Ø95、小端 Ø80，中段用 Ø65 简化；筋条、倒角和实际公差需接入官方 CAD。

几何与动作参数在 `src/gripper/model.ts`：张开净距112、夹矿65、夹头80、头部颈宽64、肩宽86、肩厚12、托唇内伸8 mm。`poseAt` 保证先接近再闭合、夹头落座后先张开再退出，存矿先支承再释放。动作只展示工具端平移，不代表六轴臂可达性、碰撞或接触仿真；底座锁紧是释放前提，其执行器未在此页设计。

受力区使用加速度3 m/s²、载荷系数2，可调头重、重心偏距和摩擦系数；输出为纯摩擦假设下的每指法向力、偏心弯矩及包含0.45 kg夹爪总成预算的总负载，不是电机扭矩。默认2.5 kg头的总负载2.95 kg，距3 kg额定仅余0.05 kg。

该入口与总装页一起经 Vite 多入口构建到 `dist/`，沿用现有 Workers 静态部署。测试：`npx playwright test tests/gripper.spec.ts`。

## 底座与线束独立页

从页头或总装“对接”进入 `/dock.html`。三个工作区分别回答：怎么找准位置、触点接哪条线、焊完需要留多大空间。

- **导向与锁紧**：外圈喇叭口 → 圆销＋菱形销 → 三点承压 → 双侧拉紧。可试摆X/Y偏移与偏航；入口余量只检查底框平面投影，不是自导正、碰撞或受力仿真。入口外禁止播放强行压入；“隐藏头底框”用于看承压点和销。
- **触点与信号**：12项逻辑功能沿用电气接口说明，选触点或表格查看车侧来源、头侧去向和标准裁判四芯对应。头侧从底部观察时左右镜像，逻辑号不变。C0为尚未接线的控制参考地备用空间；图中触点均未指定料号 / 额定电流。
- **焊线与留空**：头侧抬高70 mm作检修展开；头/车两侧都显示焊尾、热缩直段、90°弯线与线夹。可调绝缘外径、硬尾长度、直段与中心线R/外径比例。三维单线用来辨识去向，实际两条CAN分别双绞；浮动盒仍需另留服务弯。

默认4 mm功率线外径、8 mm端子/焊尾、12 mm热缩直段、中心线R=16 mm、间隙3 mm：每侧焊尾后深度41 mm，侧向弯线预留21 mm；按当前头/车焊尾基准面合计闭合总高116 mm。这个预算不含保护板、安装耳、防反插凸台、检修工具与服务环，不是已选线材或连接器规格。

尺寸、12项功能和计算在 `src/dock/model.ts`。按钮可下载当前接口参数JSON和触点CSV。构建入口包含`index.html`、`gripper.html`、`dock.html`、`wiring.html`；总装页继续展示总体对接关系，新底座尚未替换旧总装几何。独立检查：`npx playwright test tests/dock.spec.ts`。

## 底盘—头部接线页

打开 `/wiring.html`，从车侧电源/控制源沿线查看触点和头内设备。可按发射电源、Mini PC、裁判四芯、自有CAN、在位检测高亮，勾选“仅看所选支路”单独展开。地址保留支路与展开状态；点击触点编号进入底座页对应触点。支持下载带样式的SVG及触点CSV，手机端图纸和表格可横向滚动。

- Mini PC接口24 V经A1/A2直达LBC3顶板；顶板承担电脑支路保护与降压，不额外画保护模块。
- Ammo-Booster经F1/F2、自有CAN经C1/C2接入同一块动力分电＋CAN分线板；板上输出两路电调电源及三路CAN，分别到左C620、右C620和LBC3收发器。C620再接M3508三相和传感器线；不另画削波/泄放模块。车载供弹执行器留在同一受控电源支路。
- 裁判四芯保留车侧故障保护与头侧误接保护；CTRL_CAN与裁判CAN独立，三路分线口属于同一条自有总线。LBC3只从分电板接CAN，供电仍单独走Mini PC。CAM1与MIPI不跨触点。

图中线条表示线束而非单芯；芯数、回流和官方四芯颜色在支路说明及表格中。线径、线长和连接器未定。电调瞬态处理与顶板耐受按实际硬件确认；两路供电分开不代表电气隔离。

触点与底座共用 `src/dock/model.ts`，A1/A2位置不变，功能名更新为MINIPC_24V/MINIPC_RETURN；AUX内部键保留以兼容原有几何/导出。`src/wiring/model.ts`组织支路说明，`diagram.ts`绘制SVG。接线页不加载Three.js与CAD。检查：`npx playwright test tests/wiring.spec.ts tests/dock.spec.ts`。

## 本地运行

在本目录执行（Node.js 22.12或更新版本；CI使用根目录`.node-version`指定的Node 22）：

```bash
npm ci
npm run dev
```

浏览器访问终端给出的5173端口地址。同一局域网可用这台机器的IP访问。开发服务器默认监听全部网卡，勿在不可信网络长期开放。

```bash
npm run build          # 检查GLB/下载件，生成布局参数，类型检查，输出dist/
npm run check:dist     # 检查生产资源和Workers单文件大小限制
npm run deploy:check   # Wrangler本地打包检查，不发布
npm run preview        # 用4173端口检查生产构建
npm test               # 单球状态、库存、互锁和10/12发循环
npm run test:browser   # 先build；实际浏览器检查页面、动画、选取和下载
```

浏览器检查优先使用系统Chromium，也可设`CHROMIUM_PATH`。无系统浏览器时安装Playwright浏览器：`npx playwright install chromium`。测试使用软件WebGL兼容无GPU的CI环境。

## 怎么看这套结构

- **总装**：车侧单盘有序储弹，仓与头共用俯仰托架；机械臂只搬运可拆头。10/12发可切换，俯仰范围−15°～+45°。
- **装弹**：俯仰回零，打开后上方翻盖，沿炮口方向人工放入最高格；球完全入格、手退出后，保持开盖并点动一格，重复装填，全部装完再关盖。装填时禁止推送和发射，关盖时禁止装退弹。取出弹丸走相反方向。库存逐格记录，可只装部分格位。“重置为空仓示例”是演示重置，不是自动退弹。
- **供弹**：最低格与入口同轴。开门→推到轮组接管→出球→退净→关门→分度；可暂停、继续；补装请切到“装弹”。部分装填时先越过空格再送弹。每发演示5秒，不代表实际射速。
- **对接**：头下降时套管缩回；底座承载、独立拉紧后，再伸套12 mm。拆头需清空接缝和关门。夹爪、锁紧驱动与触点为功能占位。
- **视觉组件**：相机在测速上方，电脑与相机共刚性底架。可隐藏上盖及分解观察，分解时排线隐藏；分解不表示连着排线的实际拆装轨迹。

工作区切换会应用相应显示预设，并停止当前供弹动画。装填盖未关好或装退弹/分度未完成时，先完成操作再切换工作区。复选框始终显示当前图层状态；“全部显示”恢复完整装配。点选结构后，可在详情下载原参考CAD。保存图片仅导出三维画布；分享地址保留工作区、容量、俯仰与所选结构，不保存任意旋转后的相机姿态。

## 哪些来自实物参考，哪些仍在设计

| 内容 | 当前来源与含义 |
|---|---|
| 摩擦轮 | 用户确认交龙同款；取原参考Ref_1204～1207，不重用旧3510电机 |
| M3508 | 用户指定；当前显示去减速箱本体参考，轴端、轮芯与新座的配合还需设计。下载为官方完整带减速箱原件，文件名与说明保留两者区别 |
| C620 | 用户提供STEP；头侧2块，显示本体与固定接头，移除原软线姿态后画总装线缆意向 |
| SM11 | 已有2020版STEP；保留测速本体和瞄准器，原线缆姿态未沿用 |
| 相机＋LBC3 | 独立V2结构与实际CamAdaptor；相机按尺寸图建外形，部分插头/风扇为尺寸参考 |
| 仓、推杆、分度、止弹、底座、托架 | 前端生成的自制结构意向；执行器没有库存型号，以紫色占位，不是可购买器件规格 |

`public/models/manifest.json`记录CAD来源、显示子集、尺寸单位和三角面数；它和布局下载JSON由`predev`/`build`生成，不纳入版本。用户已确认提供的厂家模型允许公开展示。交龙原参考保留来源身份，整套网页不将参考设计声明为本项目原创。

底部头部外形为当前静态布置的轴对齐包络，不含夹爪、弹盘和车侧托架；新座、侧耳及保护板占位计入，紧固件和插头未完整展开。质量未实称。此页面没有整车/真实六轴臂模型，不能据此判断整车收纳、可达性或受力合格。V2组件原有的几何检查不等于新整头总装已完成干涉或实球接触验证。

本轮默认车侧pitch轴为X=−30、Z=−112 mm，放在头下承载框下方；这与此前计算中使用过的Z=−70 mm示例不同。切勿把当前布局与旧力矩表当成同一候选。下载的布局JSON保留当前基准；底盘、实际轴承与驱动接入后再联合校核。

## 装填口与规则依据

蓝色前、后挡板是固定整片，封住其余格位的两端；米色转盘夹在中间带球分度。金色小翻盖仅封后上方装填口。挡板默认不透明并在表面标名，“透视挡板”仅改变显示，不代表实物透明或拆除了挡板。

当前采用后挡板最高格处的单格服务口：Ø47 mm，中心`X=-149, Y=0, Z=2R`；盘厚50 mm，格位Ø46 mm。前挡板在这一格保持封闭，避免装入后从另一端穿出。54×54×3 mm翻盖的铰链位于口上方27 mm，向后上方翻开110°；外侧锁扣/手柄与铰链为结构意向。球从`X=-240`沿轴向放到`X=-120`，动作不经过底部推头、中心轴承横梁或摩擦轮。该通道用于人工逐发放入和取出，不是散弹漏斗。

装填模式：推头退净、出口关闭、俯仰回零、发射禁用；开盖可人工触发单格点动；装退弹动作完成、球完全入格且手与工具退出后再转盘，不自动连转。实际硬件需要盖闭合检测、可靠锁扣与断电定位；界面的互锁尚不是电气实现。Ø47口径、上翻空间和持球手指/工具空间仍需打印试件检查。卸球可从同一口取出；口径只略大于球，取球工具或后续退出辅助结构仍需试装，动画未建手指模型。

规则核对使用仓库`references/`内《RoboMaster 2027 机甲大师高校联盟赛比赛规则手册 V1.0.0（20261015）》：

- 印刷页17–18，表3-2/3-3：三分钟准备阶段可预装42 mm弹丸，初始允许发弹量为0。
- 印刷页36，3.3.3：补给区兑换的是允许发弹量，42 mm为10金币/发；不是实弹补充服务。
- 印刷页47，5.3：准备阶段允许为机器人预装弹丸。
- 印刷页54，R7–R9：弹丸来源受管控；一场结束后须清空并归还弹丸。不能理解为可自行带弹随意入场。

10/12格保留为打样与十发考核配置，不代表整局容量已经足够。库存与裁判系统允许发弹量是两套状态；当前网页仅演示实弹库存和动作，不模拟金币或裁判发弹额度。

## 更新模型

正常`npm ci && npm run build`不需要FreeCAD。已经导出的6个GLB和CAD下载件均在`public/`，构建不访问仓库外路径或CDN。

CAD修改后，在FreeCAD/FreeCADCmd中执行：

```python
p = '/home/ww/codings/zenith/frontend/scripts/export_cad.py'
exec(compile(open(p).read(), p, 'exec'), {'__file__': p})
```

它读取已有源模型，重新输出GLB及复制下载件，不覆盖源CAD。再运行`npm run build`生成来源清单和布局参数。GLB采用glTF标准Y-up，导入后恢复本工程Z-up毫米坐标；不把STEP直接塞进浏览器解析。

- `src/layout.ts`：本轮共用布局基准；修改后检查`scene.ts`内相关座、导路和孔位，不能只改一处就认为整套参数化闭合。
- `src/scene.ts`：Three.js场景、CAD资产、占位件、渲染与拾取。
- `src/state.ts`：与渲染分开的装配状态与供弹循环。
- `src/catalog.ts`：各结构说明、来源及下载。
- `src/main.ts`、`src/style.css`：控制与响应式界面。

## 推送main后部署到Cloudflare Worker

参考[`rm_course`的部署工作流](https://github.com/starwey604/rm_course/blob/main/.github/workflows/deploy.yml)与[Wrangler配置](https://github.com/starwey604/rm_course/blob/main/wrangler.toml)，沿用Workers静态资源路径和本工程npm锁文件。配置位于`frontend/wrangler.toml`，Worker名为`zenith`，资源目录为`dist/`。新增的`worker/index.ts`仅将`/api/comments`及子路径通过`COMMENTS_SERVICE`绑定转发到独立评论Worker；其他路径保留原静态资源行为，域名绑定不变。

### 设置GitHub Secrets

在任何已登录`gh`的终端运行，按提示粘贴值，不把Token写进命令参数或仓库：

```bash
gh secret set CLOUDFLARE_API_TOKEN --repo starwey604/zenith
gh secret set CLOUDFLARE_ACCOUNT_ID --repo starwey604/zenith
```

第一项是有Worker部署权限的Cloudflare **API Token**，可沿用`rm_course`同类权限并限制到目标账户；第二项是对应的Cloudflare账户ID，不是Zone ID。官方设置说明见[Workers GitHub Actions](https://developers.cloudflare.com/workers/ci-cd/external-cicd/github-actions/)。

### 发布与域名

提交并推送到`main`后，[部署工作流](../.github/workflows/deploy.yml)依次安装依赖、运行供弹状态测试、构建并检查资源、执行浏览器检查、Wrangler dry-run，通过后部署。PR只做检查；手动运行也仅允许main发布：

```bash
gh workflow run deploy.yml --repo starwey604/zenith --ref main
```

首次成功部署后，由用户在Cloudflare的`Workers & Pages → zenith → Settings → Domains & Routes → Add → Custom Domain`添加 **`zenith.silkenkite.ink`**。域名不写进`routes`，后续CI只更新Worker代码和静态资源，保留控制台域名设置。自定义域名操作见[Cloudflare说明](https://developers.cloudflare.com/workers/configuration/routing/custom-domains/)。

完整产物位于`frontend/dist/`。GLB与CAD按需请求，CAD不参与首屏下载；当前三维GLB合计约4.2 MB，CAD下载合计约42 MB。文件名带内容指纹的JS/CSS长期缓存；稳定文件名的模型与CAD每次请求重新验证，避免模型更新后仍显示旧版。

CI只拉取`frontend/public/downloads/*.FCStd`的Git LFS实体，不下载机械源文件与全部规则PDF。构建会拒绝未拉取的LFS指针。新检出仓库若禁用了LFS自动下载，在仓库根目录执行：

```bash
git lfs pull --include='frontend/public/downloads/*.FCStd' --exclude=''
```

Wrangler固定为4.156.0，兼容日期为2026-10-23，均与参考仓库一致。`npm run deploy`会真的发布，手动使用前先完成`npm run build && npm run check:dist`并通过Wrangler的正常认证流程；`npm run deploy:check`只做本地打包。

## 方案讨论与匿名评论

总装、夹爪、底座、整头接线页末尾已接入 Twikoo 评论组件。按需加载，提交时可附带当前部件、版本和公开参数；取消勾选则不附带。真实服务通过构建变量 `VITE_TWIKOO_ENV_ID` 配置，未配置时禁用评论并明确提示，不假装保存成功。

Workers + D1沿用现有Cloudflare账号，不需要注册Twikoo、MongoDB或邮件服务。独立后端为`zenith-comments`，D1实际名称为`zenith`；初始密码由所有者通过Wrangler secret配置，评论提交后直接公开，无需审核。前端构建变量已设为`/api/comments`，正式入口随前端发布生效。初始化、接入及运维见[`src/comments/README.md`](src/comments/README.md)与[`services/comments/README.md`](../services/comments/README.md)。GitHub Issue同步和GPT增量导出接口仍是后续工作。
